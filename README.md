A simple Python-based application for managing blood donation records with a user-friendly interface. Built using Tkinter for the GUI and SQLite for data storage.

Features:

1. User Authentication: Secure login system with username/password validation

2. Donor Registration: 
       
       Register new donors with comprehensive validation:Age verification (must be 18+)
       Blood group selection (A+/A-/B+/B-/O+/O-/AB+/AB-)
       Phone number format validation
       Health issue tracking
       
3. Donation Tracking: Record and track blood donation history for each donor

4. Donor Management:

        View all registered donors with complete details
        Search donors by blood group type

5. Donation Records: Display complete donation history with dates

6. Database Integration: SQLite database with proper relationships and constraints

7. GUI Interface: Clean Tkinter-based login form with dark theme

Technologies Used:

Python 3

Tkinter (GUI framework)

SQLite (Database)

Random module for ID generation

Installation & Usage:

1. Ensure Python 3.x is installed
2. Run PROJ.py to start the application
3. Login with default credentials: johnsmith / 12345
4. Use the console menu to manage donors and donations

This system helps blood banks and donation centers efficiently manage donor information and track donation records. Perfect for small-scale blood donation management operations.
